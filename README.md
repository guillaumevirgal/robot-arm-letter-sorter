# 4-DOF Robot Arm Control

A 4-DOF robot arm developed as a group submission for the *Robotic Mechanical 
Systems* course at Heriot-Watt University (2026).


## What This Is

The project covers the design, control, and implementation of a 4-DOF robot 
arm. The system includes forward and inverse kinematics, motion planning, 
and motor control. The end deliverable was a working physical arm capable 
of picking up letters and placing them in a target location depending on the name written on the letter.

## Contributors

This was a group coursework submission. Contributions:

- **Guillaume Virgal:** all software, control algorithms, and embedded code
- **Jonathan Higgs:** mechanical CAD design and assembly

The repository contains both software and mechanical design files.


## Course Context

Submitted for *Robotic Mechanical Systems* B51RO at Heriot-Watt University, 2026. Supervised by Xianwen's Kong.
